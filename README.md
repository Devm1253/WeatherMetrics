# WeatherMetrics

WeatherMetrics is a JavaFX application that analyzes weather data from CSV files and displays the results in a simple dashboard.

## Features

- Import and analyze weather CSV files
- View average temperature, humidity, and precipitation
- Filter weather data by month or year
- View weather charts and historical records
- Count days above a selected temperature

## Technologies

Java 23 · JavaFX · Maven · CSV

## How to Run

Make sure Java 23+ and Maven are installed, then run:

```bash
mvn compile javafx:run
```

The application loads sample weather data automatically. You can also import your own CSV file.

## Java Features Used

The project uses records, interfaces, streams, lambdas, enhanced switch statements, text blocks, and Markdown Javadoc.
