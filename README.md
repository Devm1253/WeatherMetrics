# WeatherWise

WeatherWise is a Java 23 weather data analyzer that processes CSV files to analyze temperature, humidity, and precipitation. The application uses JavaFX and CSS to provide an interactive weather dashboard.

## Features
- Import weather data from CSV files.
- Calculate monthly average temperatures.
- Find days above a selected temperature threshold.
- Count rainy days.
- Categorize weather as Hot, Warm, Mild, or Cold.
- Display weather statistics using charts and tables.

## Technologies
- Java 23
- JavaFX and CSS
- Maven
- CSV Data Processing

## Java Features
- Records and Interfaces
- Enhanced Switch Expressions
- Pattern Matching
- Lambdas and Streams
- Text Blocks
- Markdown Javadoc

## Running the Project

**Requirements:** JDK 23 and Maven

```bash
mvn clean compile
mvn javafx:run
```
